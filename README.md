#### Core Functionality
- User can view a new affirmation once a day 💛
- User can interact with something (i.e. card, scroll, animation) to reveal their affirmation 💛
- User can input their name to customize the daily welcome ❤️
- User can input categories/goals to customize their affirmations ❤️
- User can modify their name in settings ❤️
- User can modify their goals in settings ❤️
- User can receive a daily notification about their affirmation ❤️
- User can turn on/off notifications ❤️
- User can modify the time of the notifications (i.e. morning, afternoon, evening) ❤️
- User can view all past affirmations, organized by date in a Journal tab ❤️
- User can filter past affirmations by categories and favourites ❤️
- User can favourite/unfavourite affirmations ❤️

# GLMR
An Affirmation App

### Summary
A daily affirmations app with an interactive element.

### Requirements
- User can view a new affirmation once a day
- User can interact with something (i.e. card, scroll, animation) to reveal their affirmation
- User can view affirmation from the Home Screen via a Widget
- User can receive a daily notification about their affirmation
- User can turn on/off notifications
- User can view the affirmation and the categories.
- User can view past affirmations, organized by date
- User can favourite and unfavourite affirmations
- User can view favourited affirmations
